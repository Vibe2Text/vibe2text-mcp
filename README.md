## Что это

[Vibe2Text](https://vibe2text.ru) — онлайн-сервис транскрибации аудио и видео в
текст. Загружаете запись встречи, интервью, подкаста, лекции или телефонного звонка
— получаете готовый транскрипт: с разделением по спикерам, таймкодами, кратким
содержанием, списком задач и возможностью задавать вопросы по записи на естественном
языке. Распознавание русской речи — основной сценарий; английская и смешанная речь
тоже поддерживаются.

Этот репозиторий — про **встроенный MCP-сервер** Vibe2Text: он даёт внешним
AI-агентам (Claude, Cursor, ваши пайплайны на LangChain/LlamaIndex или собственный
клиент) программный доступ к расшифровкам — загружать записи, читать транскрипты и
редактировать их через Model Context Protocol.

## Возможности сервиса

- 🎙️ **Транскрибация аудио и видео в текст** — точное распознавание речи онлайн.
  Нейросеть переводит аудио в текст за минуты, в разы быстрее реального времени.
- 👥 **Диаризация спикеров** — определяет, кто и когда говорил. Расшифровка аудио в
  текст читается как диалог, а не как сплошная простыня.
- 🕒 **Пословные таймкоды** — каждое слово привязано ко времени, удобная навигация.
- 📝 **Краткое содержание** — AI-саммари записи в один клик.
- ✅ **Action items** — извлечение задач и решений из разговора.
- 📑 **Автоматические главы** — запись разбивается на смысловые разделы.
- 💬 **Чат по транскрипту** — вопросы к записи на естественном языке.
- 📚 **Базы знаний (KB)** — семантический поиск по всему архиву расшифровок.
- 📊 **Smart-reports** — сводные отчёты по нескольким записям сразу.
- 🔗 **Импорт по ссылке** — транскрибация видео с YouTube, RuTube, VK, Vimeo и
  прямых ссылок на `mp3`/`mp4`.
- 📄 **Экспорт** — DOCX, PDF и субтитры SRT из видео.
- 🤖 **Telegram-бот** — [@vibe2text_bot](https://t.me/vibe2text_bot): пришлите боту
  голосовое, аудио или видео — он вернёт расшифровку речи в текст прямо в чате.
- 🔌 **MCP-сервер** — доступ к транскриптам для внешних агентов (см. ниже).

## Поддерживаемые форматы

**Аудио:** `mp3` · `wav` · `m4a` · `ogg` · `opus` — голосовые, диктофон, подкасты.
**Видео:** `mp4` · `mov` · `webm` — транскрибация видео в текст, субтитры SRT.
**Импорт по ссылке:** YouTube · RuTube · VK · Vimeo · прямые ссылки на файл.

Длинные записи (многочасовые совещания, лекции) обрабатываются автоматически —
транскрибация длинных аудио в текст не упирается в ручную нарезку.

## MCP-сервер

Vibe2Text поднимает **MCP-сервер** на `https://api.vibe2text.ru/mcp` (Model Context
Protocol, streamable-HTTP). Любой MCP-совместимый агент получает те же примитивы,
что и веб-приложение: загрузка записи, распознавание речи, чтение и редактирование
транскрипта. То есть транскрибация и расшифровка аудио в текст встраивается прямо в
ваши AI-пайплайны.

### Авторизация

Долгоживущий токен из личного кабинета на vibe2text.ru:

```
Authorization: Bearer mcp_<token>
```

Конфиг для Claude Desktop / Claude Code / Cursor:

```json
{
  "mcpServers": {
    "vibe2text": {
      "url": "https://api.vibe2text.ru/mcp",
      "headers": { "Authorization": "Bearer mcp_xxx" }
    }
  }
}
```

После подключения агенту можно сказать: *«загрузи запись встречи, сделай саммари и
переименуй Спикера 2 в Анну»* — он сам вызовет нужные инструменты.

### Инструменты: загрузка и транскрибация

Работают с токеном аккаунта (`mcp_…`).

| Инструмент | Что делает |
|---|---|
| `request_upload_url` | Выдаёт signed S3-URL для загрузки аудио/видео (PUT файла) |
| `complete_upload` | Финализирует загруженный по ссылке файл |
| `submit_file_for_transcription` | Запускает транскрибацию загруженного файла |
| `upload_from_url` | Импорт+транскрибация по ссылке (YouTube/RuTube/VK/Vimeo, прямые mp3/mp4) |
| `get_import_status` | Статус импорта по ссылке (downloading/ready/failed) |
| `list_transcripts` | Каталог расшифровок: id, заголовок, статус, прогресс |
| `get_transcript_status` | Статус одной расшифровки + прогресс |

### Инструменты: чтение транскрипта

| Инструмент | Что делает |
|---|---|
| `get_transcript_summary` | Снимок транскрипта: спикеры, сегменты, главы, мета. Вызывать перед правками |
| `find_segments` | Поиск сегментов по подстроке (до 20 результатов) |

### Инструменты: редактирование спикеров и текста

Работают по конкретному транскрипту 

| Инструмент | Что делает |
|---|---|
| `rename_speaker` | Переименовать говорящего |
| `set_segment_speaker` | Переназначить реплику другому спикеру |
| `edit_segment_text` | Полностью переписать текст сегмента |
| `replace_text_in_range` | Заменить срез символов внутри сегмента (точечная правка опечатки) |
| `split_segment` | Разрезать сегмент в позиции символа |
| `merge_segments` | Склеить две соседние реплики |
| `delete_segment` | Удалить реплику |

### Инструменты: аннотации и главы

| Инструмент | Что делает |
|---|---|
| `add_annotation` | Выделить подстроку аннотацией (highlight/note) |
| `edit_chapter_title` | Переименовать главу |
| `regenerate_chapters_for_range` | Пересобрать главы в диапазоне времени (AI, async job) |

### Инструменты: версии и откат

Каждая правка снимается в snapshot — любое действие обратимо.

| Инструмент | Что делает |
|---|---|
| `take_snapshot` | Снять снимок состояния транскрипта |
| `list_snapshots` | Список снимков (метаданные) |
| `restore_snapshot` | Откатить транскрипт к снимку (откат тоже обратим) |

### Подключение из кода

```bash
export VIBE2TEXT_MCP_URL="https://api.vibe2text.ru/mcp"
export VIBE2TEXT_TOKEN="mcp_xxx"
```

## Частые вопросы (FAQ)

**Как перевести аудио в текст через API?**
Загрузите файл (`request_upload_url` → PUT → `submit_file_for_transcription`) или
поставьте ссылку (`upload_from_url`) — сервис выполнит распознавание речи и вернёт
транскрипт. То же самое доступно одним запросом из любого MCP-агента.

**Как сделать транскрибацию видео с YouTube?**
Передайте ссылку в `upload_from_url` — поддерживаются YouTube, RuTube, VK, Vimeo.
Сервис скачает запись, выполнит транскрибацию видео в текст и вернёт результат.

**Поддерживается ли распознавание русской речи?**
Да, распознавание русской речи — основной сценарий; английская и смешанная речь
тоже распознаются.

**Можно ли расшифровать аудио в текст бесплатно?**
На vibe2text.ru есть бесплатный лимит, чтобы попробовать транскрибацию без оплаты.
Дальше — по тарифам за длительность записи.

**Можно ли откатить правку транскрипта?**
Да. Каждая правка снимается в snapshot, а `restore_snapshot` возвращает прежнее
состояние — причём откат тоже обратим.
